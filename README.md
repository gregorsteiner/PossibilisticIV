This repository contains the code to reproduce the findings in our paper "Possibilistic Instrumental Variable Regression with Potentially Invalid Instruments" ([arxiv:2511.16029](https://arxiv.org/abs/2511.16029)). The code for the simulation experiments can be found in `simulations/simulation.jl` and `simulations/multiple_instruments_simulation.jl` for the single and mutliple instrument scenarios, respectively. `applications/AJR_Example.jl` and `applications/schooling_example.jl` include all the code to reproduce the real-data applications.
