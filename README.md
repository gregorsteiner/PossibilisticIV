This repository contains the code to reproduce the findings in our paper "Possibilistic Instrumental Variable Regression" ([arxiv:2511.16029](https://arxiv.org/abs/2511.16029)). The code for the simulation experiments can be found in `simulation.jl` and `multiple_instruments_simulation.jl` for the single and mutliple instrument scenarios, respectively. `AJR_Example.jl` and `schooling_example.jl` include all the code to reproduce the real-data applications.
